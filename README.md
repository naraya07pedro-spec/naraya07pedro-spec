### 🛡️ Core Engineering Principles

1. **Design for System Failure First:** Every external network call, AI response, or third-party webhook is assumed unstable until verified.
2. **Deterministic & Idempotent Workflows:** Workflows can be safely re-executed or retried without producing duplicate side-effects or corrupting database state.
3. **Explicit Human-in-the-Loop Controls:** Sensitive, high-cost, or destructive AI operations require explicit authorization boundaries before writing to persistent state.
