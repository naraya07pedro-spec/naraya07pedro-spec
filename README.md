## Engineering approach

- Put deterministic gates around irreversible or high-risk actions.
- Treat state, deduplication, and idempotency as first-class design concerns.
- Make failure states visible instead of relying on silent recovery.
- Keep AI decisions bounded by explicit inputs, tools, and review boundaries.
- Build reviewable evidence so another engineer can inspect the implementation quickly.
