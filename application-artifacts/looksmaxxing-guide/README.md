# looksmaxxing.guide — AI task artifact

Small static prototype built specifically for an application task.

## What it does

Turns the site's existing manual six-category Looksmax Score formula into an interactive client-side calculator:

- Facial Harmony — 25%
- Physique & Fitness — 20%
- Skin Quality — 15%
- Hair — 15%
- Grooming & Style — 15%
- Jawline Definition — 10%

It also identifies the lowest self-rated category so the user has a clear next area to review.

## Constraints

- No backend
- No dependencies
- No tracking
- No medical claims
- Keeps the site's own self-assessment framing

Open `index.html` directly in a browser.
